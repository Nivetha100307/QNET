## Integrated System Capabilities

### Module 5 — Secure SCADA Communication Engine
- **E91 QKD Key Retrieval**: Real-time CHSH Bell parameter $S=2.82$, QBER $1.2\%$, secret key rate 1.45 kbps.
- **Key Derivation**: HKDF-SHA256 expanding raw quantum key into 256-bit AES session key.
- **Authenticated Encryption**: **AES-256-GCM** encryption with 96-bit random nonces and 128-bit authentication tags.
- **Replay & Freshness**: Monotonic sequence tracking, nonce deduplication, and timestamp windowing.
- **Telemetry Streaming**: Real-time 1s grid telemetry snapshot over WebSockets.

### Module 6 — Zero-Trust Authentication & Integrity Engine
- **Identity Management Service**: Comprehensive entity registry for substations, RTUs, PLCs, operators, and autonomous AI agents.
- **HMAC-SHA256 Authentication**: Constant-time `hmac.compare_digest()` preventing timing side-channel attacks.
- **Role-Based Access Control (RBAC)**: Matrix supporting `GRID_ADMIN`, `SUBSTATION_ENGINEER`, `CONTROL_OPERATOR`, `FIELD_ENGINEER`, `VIEWER`, `AI_AGENT`.
- **Adaptive Dynamic Trust Engine (0–100)**: Dynamically penalizes trust scores on security anomalies (Auth fail $-10$, Replay $-20$, Tampering $-35$). Automatically isolates devices when trust drops below $50.0$.
- **Unified Security Decision Engine**: Decision orchestrator gathering all 20 verification checks and returning a machine-readable JSON rationale object.

## Module 6 REST API Endpoints

- `POST /api/zero-trust/verify`: Executes 20-stage Security Decision Engine pipeline.
- `POST /api/zero-trust/authenticate`: Authenticates device identity & HMAC signature.
- `POST /api/zero-trust/authorize`: Verifies RBAC permission matrix for role and command.
- `POST /api/zero-trust/verify-hmac`: Constant-time HMAC-SHA256 signature verification.
- `POST /api/zero-trust/verify-integrity`: SHA-256 fingerprint & structural integrity check.
- `POST /api/zero-trust/update-trust`: Dynamic trust score update endpoint (PENALIZE, REWARD, RESET).
- `GET /api/zero-trust/trust-score/{device_id}`: Retrieves dynamic trust score & reputation.
- `GET /api/zero-trust/devices`: Zero-trust registered entity inventory.
- `GET /api/zero-trust/metrics`: Operational & Zero-Trust security metrics snapshot.
